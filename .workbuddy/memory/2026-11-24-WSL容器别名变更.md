# WSL 容器别名变更（2026-11-24）

## 用户确认的新别名

| 修改前 | 修改后 |
|---|---|
| `mysql_wsl` | `mysql8.0` |
| `opengauss` | `gauss3.0` |
| `redis_wsl` | `redis7` |
| `kafka-wsl` | `kafka4.0` |
| `pg_wsl` | `pg16` |
| `es-wsl` | `es7` |

## Elasticsearch 资源调整

- ES JVM 堆已调大为 `350m`。
- ES 容器内存已调大为 `700m`。
- 原因：默认堆过小导致 GC 频繁、CPU 消耗过高。

## 对当前任务的影响

- 本机复测脚本与文档中的容器名应以新别名为准。
- 仍应兼容旧名称读取历史脚本，但新脚本优先使用新别名。
- 服务代码修改后必须清理旧版本服务包，避免误启动旧 jar/binary。
