# backend 认证态全端点清单（跨语言统一：Java8 基线 vs Go / Python / Rust）
# 用于 backend-auth-parity-cloud 的「全端点」业务校验。
#
# 端点来源（v2 全端点扩展，2026-11-18）：
#   从 ruoyi-admin 的 81 个 Controller 自动提取全部 HTTP 端点（Java 共 400 个），
#   与 Go/Python/Rust 源码提取的端点取交集（四语言共有 158 个），再按安全边界过滤：
#     - 仅保留四语言均实现的「相同端点」（满足"相同端点业务一致性验证"要求）；
#     - 仅保留纯 GET 只读端点（排除 POST/PUT/DELETE 写操作，避免污染 dump→restore）；
#     - 排除副作用型 GET（sync/retry/refresh/clear 等，避免触发数据同步）；
#     - 排除路径参数端点（{id} 需真实主键，跨实例不可比）与文件流端点（export/download）；
#     - 排除运行时配置展示端点（/base/cdc/config：Java 暴露完整 CDC 配置 51KB，
#       其它语言返回精简配置，属配置结构差异而非业务数据差异）。
#   最终 71 个可直接探测的只读端点（含 / 与 /captchaImage）。
#
# 安全约束（与前几轮独立审阅一致）：
#   - 探针自动登录注入 Bearer token；密码走 env 不进 argv；
#   - 对 body.code ∈ {401,403,500} 或 HTTP>=500 做绝对失败断言，防 HTTP200 假绿。
