# backend 认证态全端点清单（跨语言统一：Java8 基线 vs Go / Python / Rust）
# 用于 backend-auth-parity-cloud 的「全端点」业务校验。
#
# 端点选择原则（已逐条核对 Java8 基线 master 分支源码）：
#   - 全部为只读 GET，不触发写操作，避免污染 dump->restore 数据集；
#   - 仅保留基线 master 确实注册的端点，避免基线 404 造成无意义对比；
#   - 必需查询参数已补齐（tollGantryFwqList 的 type 为 @RequestParam required）；
#   - RuoYi 业务端点需 Bearer token（探针自动登录注入）；
#   - 探针会对 body.code ∈ {401,403,500} 做绝对失败断言，避免 HTTP 200 假绿。
#   - 已剔除基线 master 不存在的 /monitor/bigscreen/* 与 /export/approvals
#     （这些是 feature/jdk21 才有的 v3 端点）。
