## 快速结论

1. **api cd-standalone 核验**：原先 `service=java` 只产 java；push(all) 产 java/go/python；rust/cpp 因源码不在 master 长期跳过，csharp/kotlin 无源码。用户确认"补齐缺失语言"。
2. **api 补齐方案**（已推送）：跨分支 `actions/checkout(ref=car-monit-api-rust / car-monit-api-cpp)` 拉完整源码构建 rust/cpp，纳入 tar；csharp/kotlin 如实跳过。commit：`5d289b8a` → 修 libcurl `cc1c7069`。
3. **backend cd-standalone 修复**（已推送）：verify(py) BrokenPipe（head→sed）、verify(java) 日志目录 + 落盘 grep 判定、go/rust head→sed。commit：`866611343d38`。
4. **self-hosted-ci**：backend canary 默认 runner label `wsl-k3s-api`→`wsl-k3s`（已随上面 commit 推送）；两仓库 self-hosted runner 当前离线，属环境限制。
5. **所有 push 前均经独立会话审阅 PASS**（api 两轮、backend 两轮）。
