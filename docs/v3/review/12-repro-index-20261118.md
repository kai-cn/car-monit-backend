# 12. 复现脚本索引（2026-11-18 起，含 11-20 Java POM 升级）

## 认证
- `gh_cred.py`：固定账号 token 缓存。
- `git-credential-ghcached.py`：Git credential helper，只读缓存，不弹 GCM 账号框。
- `configure-gh-credential-helper.py`：一次性配置 `credential.https://github.com.helper`。

## POM 盘点与迁移
- `survey-all-poms.py`：只读盘点所有 Java 分支 POM 版本。
- `migrate-api-jedis-to-lettuce.py`：Jedis → Lettuce 依赖与代码迁移。
- `upgrade-poms-boot-managed.py`：Boot2 升级与删除 Boot 管理依赖显式版本。
- `dedupe-redis-starter.py`：删除重复 Redis starter。
- `local-*.py`：本地 worktree 修改、提交、推送脚本，均含用途/风险注释。

## 云验证
- `dispatch-java-upgrade-verification.py`：派发 16 个 Java 分支云验证。
- `collect-java-upgrade-runs.py`：按分支收集 run 状态。
- `diagnose-failed-java-upgrade.py`：失败 run 日志摘要。
- `redispatch-java-upgrade.py`：取消旧 run 并重跑。
- 结果：`java-upgrade-runs.json`（16/16 success）。
- Java-only workflow：`.github/workflows/java-upgrade-verify.yml`。
- 失败迭代日志：`java-upgrade-logs/`。
